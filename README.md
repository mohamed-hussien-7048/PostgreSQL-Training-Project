# PostgreSQL-Training-Project

## فكرة المشروع

مشروع بسيط لإدارة بيانات الأشخاص وأرصدتهم، من خلال واجهة تقدر تستخدمها عشان تضيف شخص جديد، تعرض البيانات، تعدّلها أو تحذفها بسهولة.

المشروع معمول كتطبيق عملي على ربط **Node.js وExpress** بقاعدة بيانات **SQL Server** والتعامل مع البيانات من خلال واجهة ويب.

---

## أهم مميزات المشروع

- إضافة أشخاص وتسجيل الاسم والرصيد.
- عرض بيانات الأشخاص المسجلة.
- تعديل بيانات أي شخص أو حذفها.
- عرض إحصائيات عن عدد الأشخاص وإجمالي ومتوسط الأرصدة، حسب الوظائف الموجودة في الواجهة.

---

## التقنيات المستخدمة

- **Node.js:** تشغيل كود JavaScript على السيرفر.
- **Express.js:** إنشاء السيرفر وتنظيم طلبات التطبيق.
- **SQL Server:** تخزين بيانات الأشخاص والأرصدة.
- **HTML, CSS & JavaScript:** بناء واجهة المستخدم والتعامل معاها.
