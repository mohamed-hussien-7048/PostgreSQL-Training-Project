# PostgreSQL-Training-Project

## فكرة المشروع

مشروع لإدارة الأشخاص والأرصدة، بيسمحلك تضيف البيانات وتعرضها وتعدّلها أو تحذفها من خلال واجهة ويب بسيطة باللغة العربية.

المشروع معمول باستخدام **Node.js وExpress** مع قاعدة بيانات **PostgreSQL**، وده بيوضح إزاي نربط تطبيق ويب بقاعدة بيانات علائقية ونتعامل مع البيانات من خلال API.

---

## أهم مميزات المشروع

- إضافة شخص بالاسم والرصيد.
- عرض الأشخاص المسجلين في قاعدة البيانات.
- تعديل بيانات شخص أو حذفه.
- تخزين الأرصدة بأرقام عشرية مناسبة للقيم المالية.
- واجهة عربية بتدعم اتجاه الكتابة من اليمين للشمال.

---

## التقنيات المستخدمة

- **Node.js:** تشغيل التطبيق على السيرفر.
- **Express.js:** إنشاء API وتنظيم المسارات.
- **PostgreSQL 16:** تخزين وتنظيم بيانات الأشخاص.
- **pg:** ربط Node.js بقاعدة بيانات PostgreSQL.
- **dotenv:** قراءة إعدادات التشغيل من ملف البيئة.
- **HTML, CSS & JavaScript:** بناء واجهة المستخدم.

---

## تشغيل المشروع

1. ثبّت الحزم المطلوبة باستخدام `npm install`.
2. جهّز قاعدة بيانات PostgreSQL باسم `fahd5_db`.
3. راجع إعدادات الاتصال بقاعدة البيانات في ملف `.env`.
4. شغّل المشروع باستخدام الأمر المتاح في `package.json`.
